## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/TheKanishkDev/SoulSync-AI.git

# Backend setup
cd SoulSync-AI/backend
mvn clean install
mvn spring-boot:run

# Frontend setup
cd ../frontend
npm install
npm run dev
```
