# ⚙️ Installation Guide

</div>

## 1️⃣ Clone Repository

```bash
git clone https://github.com/TheKanishkDev/SoulSync-AI.git

cd SoulSync-AI
```

---

## 2️⃣ Frontend Setup

```bash
cd Frontend

npm install

npm run dev
```

---

## 3️⃣ Backend Setup

```bash
cd Backend

mvn clean install

mvn spring-boot:run
```

---
